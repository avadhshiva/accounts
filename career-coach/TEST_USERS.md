# Pathly — Test User Guide (pilot)

## Share with testers

1. Open the link you send (localhost via tunnel, or deployed URL)
2. Sign up with email + password
3. Try in this order (10–15 min):
   - Dashboard overview
   - Resume Studio → paste resume → score
   - Mock Interview → HR or GenAI → 3–4 answers → Finish & score
   - Learn → open any lesson → quiz
4. If limits block you: Dashboard → **Enable Pro for testing**

## What to ask them

- Was resume feedback useful?
- Did interview feel realistic?
- Would you pay ₹399/mo or ₹999/semester?
- What’s missing?

## Founder checklist before sending link

- [ ] `npm run dev` (or deploy) is running
- [ ] Signup → resume → interview works on your phone
- [ ] Terms / Privacy / Refund links load
- [ ] You are ready to collect WhatsApp feedback
